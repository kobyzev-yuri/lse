# Регламент: вкладка «Фундамент» (Рабочая тетрадка)

Краткий фон по эмитенту для тезиса удержания. Эталон UI — карточка в стиле NBIS (~20 секунд чтения).

Связанные файлы: [`TRADING_NOTEBOOK.md`](TRADING_NOTEBOOK.md), UI `/notebook` → вкладка **Фундамент**, API `PATCH /api/notebook/tickers/{sym}/fundament`, `GET …/fundament/suggest`.

---

## 1. Цель

| Это | Это не |
|-----|--------|
| Справка: суть бизнеса → 4 метрики → маржа/финансирование → плюсы/риски | Гейт Вердикта (Buy/Sell) |
| Фон для «зачем тикер в тетрадке» | Тактика входа/выхода (отдельная вкладка) |
| Ручной тезис Насти + черновик цифр | Автосигнал «покупай / продавай» |

**Анти-цели:** не гейтить BUY/SELL по фундаменту; не автогенерить плюсы/риски из LLM / Seeking Alpha без ручного approve.

---

## 2. Шаблон полей (эталон NBIS)

1. **Tagline** — 1–2 фразы: что за бизнес (+ опционально категория: «AI Cloud · Neocloud»).
2. **Четыре метрики** (имя / значение / короткий комментарий):
   - Кэш  
   - FCF  
   - Прямой долг  
   - Запас прочности (runway / current ratio / «кэш покрывает CapEx»…)
3. **Маржа** — откуда маржа / контракты / продукт vs сырая мощность.
4. **Финансирование** — кэш, долг, инвесторы, кредитные линии.
5. **Плюсы** — ≥2 пункта (value drivers).
6. **Риски** — ≥2 пункта.
7. **`filing_url`** (опционально) — прямая ссылка на 10-Q / 20-F / IR; иначе кнопка SEC search по тикеру.

---

## 3. Источники правды

| Слой | Источник | Роль |
|------|----------|------|
| Черновик цифр | **Yahoo** (`Подтянуть из Yahoo` → yfinance) | Скорость; метки в note «Yahoo …» |
| Сверка цифр после earnings | **10-Q / 10-K** (US) или **20-F / 6-K / IR** (иностранные) | Правда по кэшу/долгу/FCF |
| Tagline, маржа, финансирование (смысл), плюсы, риски | **Только Настя** (или согласованный редактор) | Голос тезиса |
| Seeking Alpha / дайджест LLM | Новости и контекст | **Не** источник истины по цифрам фундамента |

Полуавтомат: система даёт draft + ссылку на filings; смысл карточки — ручной.

---

## 4. Охват и роли

- **Обязательный** полный NBIS-стиль — для **ядра по запросу Насти** (тикеры с позицией / активным тезисом в G1–G2 в приоритете).
- Остальные тикеры тетрадки — пустая карточка или Yahoo-черновик **без** «сохранить», пока тезис не утверждён.
- G3 / Watchlist — только по запросу.

| Роль | Делает |
|------|--------|
| Система | Yahoo draft; ссылка SEC/EDGAR; хранение overlay |
| Настя | Утверждает tagline / метрики после сверки / плюсы / риски |
| Алексей / ops | Не подменяет тезис; может помочь с SEC link / деплоем |

---

## 5. Когда обновлять

| Событие | Действие |
|---------|----------|
| Тикер добавлен в ядро / «нужен фундамент» | Yahoo draft → Настя правит тезис → **OK · сохранить** |
| **T+1…T+2 после earnings** | Сверить 4 метрики с 10-Q/IR; обновить риски при сломе тезиса |
| Квартальный review | Пройти ядро: устаревшие note «Yahoo» без сверки — долг |

### «Наказание» (слом тезиса отчётом)

Не отдельный авто-гейт. Практика:

1. Добавить/усилить пункт в **Риски**.
2. Коротко поправить **Маржа** / **Финансирование**, если сломалась логика.
3. На Вердикте при необходимости выключить тумблер **тезис** (уже существующий ручной гейт).

---

## 6. Definition of Done карточки

Карточка считается заполненной, если:

- читается за **~20 секунд**;
- есть осмысленный **tagline**;
- **4 метрики** с value и коротким note;
- заполнены **маржа** и **финансирование** (хотя бы по одному абзацу);
- **≥2 плюса** и **≥2 риска**;
- после последнего earnings цифры либо сверены с filing, либо в note явно «черновик Yahoo, не сверено».

---

## 7. Риски полной автоматики (почему не делаем)

- Ложные цифры (TTM vs квартал, GAAP vs non-GAAP).
- Чужой нарратив (LLM/SA ≠ голос Насти).
- «Красивая» карточка без сверки после отчёта.
- Иностранные эмитенты без 10-Q ломают ожидание «для всех».
- Смешение справки с сигналом Вердикта.
