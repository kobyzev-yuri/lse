# Тетрадка: пробелы автозаполнения и источников

Backlog дыр. Правило не меняем: **кнопка → черновик → сверка с filing/IR → суждение Насти → OK**.

Связано: [NOTEBOOK_FUNDAMENT_REGLEMENT.md](NOTEBOOK_FUNDAMENT_REGLEMENT.md), [earnings-event-agent-lse/](earnings-event-agent-lse/).

## Зачем это важно

| Если дыра жива | Что ломается у Насти |
|----------------|----------------------|
| Brief `partial` / нет materials | «Ожидания» пустые или из случайного заголовка KB — нельзя готовиться к отчёту |
| Yahoo без сверки с Ex99/10-K | Плитки паспорта (кэш/FCF/долг) выглядят уверенно, но период/состав могут врать |
| `filing_url` = голый 8-K | Кнопка SEC открывает обёртку без цифр → потеря времени |
| Карточка не знает про новый earnings | Держим устаревший BEAT/MISS и CapEx до ручного «Подтянуть» |

**Не важно тащить в backlog:** платные fundamentals API «вместо Yahoo» без доказанного расхождения на G1; автосуждение LLM; vendor ради vendor.

## Уже работает по кнопке

| Карточка | Источник | Что даёт |
|----------|----------|----------|
| Фундамент | Yahoo + `earnings_material` / Event Brief | биржа, HQ, листинг, 4 метрики, маржа%, черновик сути/финансов, `filing_url` (Ex99/press предпочтительнее 8-K shell), CapEx/маржа из extract |
| Ожидания | Event Brief (приоритет) + KB | driver, rev/EPS, leading, CapEx, маржа, guidance, дата·BEAT/MISS·реакция, why |

Кнопка **не** пишет (намеренно): плюсы/риски, key clients, слой на Профиле, `tactics_map_ru`, `risk_shift_ru`, авто-OK.

**Цифры паспорта по умолчанию = Yahoo.** Истина после earnings = Ex99 / 10-Q / 10-K / IR. Второй API нужен только как cross-check, не как замена Yahoo.

## C. Порядок работ

1. **A1** — ops: materials + extract на G1, sufficiency показывает дыры.  
2. **A2** — brief не затирать KB.  
3. ~~**A6**~~ — Ex99 ranking (готово). Дальше при желании: предпочитать 10-K/10-Q PDF, если есть.

6. **A5 / B7** — non-US IR по запросу Насти.
