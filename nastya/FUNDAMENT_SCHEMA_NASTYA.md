# Схема «Фундамент» / «Ожидания от репорта» (Настя, 02.08.2026)

Кратко, как эталон NBIS; не доклад. Примеры репортов — **MSFT** / **META**. Вывод = сохранённые поля (не LLM).

## Матрица источников

| Поле | Источник (кнопка) | Настя |
|------|-------------------|--------|
| Биржа | Yahoo `exchange` → NASDAQ/NYSE | правка при ошибке |
| HQ / юрисдикция | Yahoo city/state/country | правка |
| Листинг / происхождение | Yahoo first trade + «founded in» из summary | дописать историю (Yandex spin-off и т.п.) |
| Сектор / слой | — | **только Настя** на **Профиле** (классификация тетрадки) |
| Суть (tagline) | Yahoo `longBusinessSummary` (1-е предл.) | переписать модель своими словами |
| Ключевые клиенты | нет стабильного API | **только Настя** (10-K / пресс-релизы) |
| Маржа % | Yahoo gross/oper/net | смысл «откуда маржа» |
| Кэш / FCF / долг / запас | Yahoo BS/CF | сверка с filing после earnings |
| Финансирование | Yahoo кэш/долг/D/E | нарратив: кто платит рост / точка разрыва |
| Плюсы / Риски | — | **только Настя** (+ консенсус с Инвестдомов) |
| Ожидания: факты A + вердикт | кнопка **новости / brief** (KB) | сверка с IR |
| Ожидания: тактика, смещение риска | — | **только Настя** |

**Правило:** всё, что умеем взять из Yahoo / KB — только по кнопке. Настя правит суждение и то, чего нет в API.

## Вкладка 1. Фундамент (паспорт)

| Блок | Поля |
|------|------|
| A | биржа, HQ, листинг (Yahoo) · слой на Профиле (Настя) |
| B | tagline draft (Yahoo) + клиенты (Настя) + маржа % (Yahoo) |
| C | 4 плитки (Yahoo) |
| D | цифры (Yahoo) + нарратив (Настя) |
| E | плюсы/риски (Настя) |

## Вкладка 2. Ожидания от репорта

| Блок | Поля |
|------|------|
| A Watch | драйвер…гайденс — KB/brief; «как в тактику» — Настя |
| B Last | дата/вердикт/за что — KB/brief; «куда сместился риск» — Настя |
